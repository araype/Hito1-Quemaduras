1Qué necesitas

ElementoDetalle
PCWindows 10 u 11, 16 GB de RAM y unos 15 GB libres. El proyecto pesa cerca de 1 GB y Unity genera otros 10 GB al importarlo.
Unity HubSe descarga de unity.com/download.
Unity 2022.3.62f3Se instala desde Unity Hub con el módulo Android Build Support, que incluye OpenJDK y el Android SDK y NDK.
Git y Git LFSSe descargan de git-scm.com; Git LFS viene incluido. Es obligatorio: los modelos, texturas y audios se guardan con LFS.
VisorMeta Quest 2, 3 o Pro, con un cable USB-C de datos.
Cuenta de MetaCon una organización de desarrollador (gratis), para activar el modo desarrollador.
OpcionalMeta Horizon Link, para probar en la PC con el visor puesto, y Meta Quest Developer Hub, para instalar el APK y ver los archivos del visor.

2Descargar el proyecto

Abre una terminal (Git Bash o PowerShell) en la carpeta donde quieras guardarlo y ejecuta:

git lfs install
git clone https://github.com/araype/Hito1-Quemaduras.git
cd Hito1-Quemaduras
git checkout mejoras-demo
Rama. La versión más reciente está en mejoras-demo. Cuando se una a main, basta con quedarse en main.
Sin Git LFS la escena queda vacía. Los archivos .fbx, .glb, .png y .wav se descargan como textos de pocas líneas y no aparecen personajes ni sonidos. Si te pasó, ejecuta git lfs pull dentro de la carpeta.

3Abrir el proyecto en Unity

  1. En Unity Hub, entra a Installs → Install Editor e instala la versión 2022.3.62f3 con Android Build Support y sus dos subopciones.
  2. Entra a Projects → Add → Add project from disk y elige la carpeta Hito1-Quemaduras.
  3. Ábrelo. La primera vez Unity importa todo y puede tardar de 15 a 30 minutos.
  4. En la ventana Project, abre con doble clic la escena Assets/Hito1/Escenas/Escenario_Quemadura.unity.
Es normal no ver todos los objetos. El botiquín, el film, la bolsa, la manta, los remedios y el reloj los crea el código al dar Play.

4Probar en la PC (opcional)

Sirve para revisar cambios sin compilar. El visor se conecta a la PC con Meta Horizon Link, por cable o Air Link.

  1. Abre Meta Horizon Link en la PC, conecta el visor y, dentro del visor, activa Link.
  2. En Unity, pulsa Play. La aplicación se ve en el visor y en la ventana Game.
  3. Para detenerla, pulsa Play otra vez.
Sin visor se puede usar el Meta XR Simulator: menú Meta → Meta XR Simulator → Activate y luego Play. En el editor, F9 pausa o continúa y F8 termina la práctica y muestra el resumen.

5Preparar el visor Meta Quest

Se hace una sola vez por visor.

  1. Crea una organización de desarrollador en developers.meta.com con tu cuenta de Meta.
  2. En la app Meta Horizon del celular, entra a Dispositivos → tu visor → Ajustes del visor y activa Modo desarrollador.
  3. Reinicia el visor.
  4. Conecta el visor a la PC por USB-C. Dentro del visor aparece ¿Permitir depuración USB?: marca Permitir siempre desde esta computadora y acepta.

6Compilar e instalar en el visor

Revisar la configuración

El proyecto ya viene configurado. Solo comprueba que esté así:

DóndeValor esperado
File → Build Settings → PlatformAndroid, con el logo de Unity al lado
Scenes In BuildSolo Escenario_Quemadura marcada
XR Plug-in Management, pestaña AndroidOpenXR y Meta XR feature group marcados
Player → Other SettingsIL2CPP, ARM64, Vulkan, espacio de color Linear y Android 12L (API 32) como mínimo

Opción A: compilar e instalar de una vez (recomendada)

  1. Con el visor conectado por cable, abre File → Build Settings.
  2. En Run Device, pulsa Refresh y elige tu visor.
  3. Pulsa Build And Run y elige una carpeta para el APK, por ejemplo Builds/.
  4. La primera compilación tarda de 10 a 25 minutos. Al terminar, la app se abre sola en el visor.

Opción B: generar el APK e instalarlo después

  1. En Build Settings, pulsa Build y guarda el APK.
  2. Arrastra el APK a Meta Quest Developer Hub (Device Manager → Apps) o instálalo desde la terminal:
adb install -r Builds/QuemaduraVR.apk
Dónde está adb. Viene con Unity en C:\Program Files\Unity\Hub\Editor\2022.3.62f3\Editor\Data\PlaybackEngines\AndroidPlayer\SDK\platform-tools\.

7Abrir y usar la aplicación

  1. En el visor, abre la Biblioteca de apps.
  2. Cambia el filtro a Fuentes desconocidas.
  3. Abre Pruebalaptop_agarrecubo.
  4. Elige Modo guiado (te indica cada paso) o Modo evaluación (lo haces solo y se mide).

8Recuperar los registros de sesión

Cada partida se guarda en el visor como un archivo JSON con el modo, el puntaje, los errores, los tiempos y la decisión médica. Son los datos de la evaluación con usuarios.

Ruta en el visor

/sdcard/Android/data/com.DefaultCompany.Pruebalaptop_agarrecubo/files/sesiones_quemadura/

Copiarlos a la PC, con el visor conectado por cable:

adb pull /sdcard/Android/data/com.DefaultCompany.Pruebalaptop_agarrecubo/files/sesiones_quemadura/ ./sesiones

También se ven en Meta Quest Developer Hub, en Device Manager → File Manager. Las partidas jugadas en el editor quedan en %USERPROFILE%\AppData\LocalLow\DefaultCompany\Pruebalaptop_agarrecubo\sesiones_quemadura\.

9Problemas comunes

ProblemaSolución
La escena no tiene personajes o se ve vacíaFaltan los archivos de Git LFS: ejecuta git lfs install y luego git lfs pull.
El visor no aparece en Run DeviceRevisa que el modo desarrollador esté activo, usa un cable de datos, acepta la depuración USB dentro del visor y pulsa Refresh.
Error de Android SDK o JDK al compilarReinstala el módulo Android Build Support, con sus subopciones, desde Unity Hub.
Error al resolver com.coplaydev.unity-mcpEs una herramienta de desarrollo que se descarga con Git. Instala Git o quita esa línea de Packages/manifest.json; la aplicación no la necesita.
Al dar Play no se ve nada en el visorAbre Meta Horizon Link, conecta el visor y activa Link dentro del visor antes de dar Play.
La app no aparece en la bibliotecaCambia el filtro a Fuentes desconocidas.
Va lento o con tironesUsa la versión compilada (APK) en lugar de Play con Link, y cierra las demás apps del visor.
