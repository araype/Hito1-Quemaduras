Guía rápida de instalación y despliegue

Simulador VR de primeros auxilios ante una quemadura doméstica

CS2H01 Interacción Humano-Computador · UTEC Unity 2022.3.62f3 · Meta Quest Versión completa, con capturas: docs/manuales/Manual_Instalacion_Despliegue.pdf

Requisitos

ElementoDetalle
PCWindows 10 u 11, 16 GB de RAM, unos 15 GB libres
SoftwareUnity Hub, Unity 2022.3.62f3 con Android Build Support, Git con Git LFS
VisorMeta Quest 2, 3 o Pro, con cable USB-C de datos y modo desarrollador

Instalación

1

Descargar el proyecto

git lfs install
git clone https://github.com/araype/Hito1-Quemaduras.git
cd Hito1-Quemaduras
git checkout mejoras-demo

Sin Git LFS la escena queda sin personajes ni sonidos; si pasa, ejecuta git lfs pull.

2

Abrir en Unity

En Unity Hub: Projects → Add → Add project from disk y elige la carpeta. La primera importación tarda de 15 a 30 minutos. Abre la escena Assets/Hito1/Escenas/Escenario_Quemadura.unity.

3

Probar en la PC (opcional)

Conecta el visor con Meta Horizon Link, activa Link dentro del visor y pulsa Play en Unity. Sin visor: Meta → Meta XR Simulator → Activate y Play.

4

Preparar el visor (una sola vez)

Crea una organización en developers.meta.com. En la app Meta Horizon del celular activa Modo desarrollador en los ajustes del visor y reinícialo. Al conectarlo por USB, acepta Permitir depuración USB dentro del visor.

5

Compilar e instalar

En File → Build Settings comprueba que la plataforma sea Android y que solo esté marcada Escenario_Quemadura. En Run Device pulsa Refresh, elige el visor y pulsa Build And Run. La primera vez tarda de 10 a 25 minutos.

Si ya tienes el APK, instálalo con Meta Quest Developer Hub o con adb install -r QuemaduraVR.apk.

6

Abrir la app

En el visor: Biblioteca → Fuentes desconocidas → Pruebalaptop_agarrecubo. Elige Modo guiado o Modo evaluación.

Registros de sesión

Cada partida se guarda como JSON en el visor. Para copiarlos a la PC, con el visor conectado:

adb pull /sdcard/Android/data/com.DefaultCompany.Pruebalaptop_agarrecubo/files/sesiones_quemadura/ ./sesiones
